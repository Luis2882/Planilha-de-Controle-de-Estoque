# 📦 Sistema de Controle de Estoque (SQL + Python)

Uma solução prática e automatizada para gerenciamento e controle de estoque, integrando a manipulação de banco de dados **SQL** com scripts em **Python** para processamento, consulta e geração de relatórios de dados.

---

## 🚀 Funcionalidades

* 📊 **Integração SQL & Python:** Conexão direta com banco de dados para leitura e escrita de dados.
* 📋 **Gestão de Inventário:** Cadastro, atualização e consulta de produtos e quantidades em estoque.
* 🔍 **Consultas Automatizadas:** Execução de queries otimizadas para monitoramento de entradas e saídas.
* 📈 **Geração de Relatórios:** Exportação e visualização dos dados do estoque para acompanhamento.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**
* **SQL** (PostgreSQL / SQLite / MySQL)
* **Pandas** (para manipulação e análise de dados)
